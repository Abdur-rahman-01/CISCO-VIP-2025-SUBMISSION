# 📡 CISCO VIP 2025 Submission

This repository contains my official submission for the **Cisco Virtual Internship Program (VIP) 2025** under the **Cybersecurity & Networking** domain. The project focuses on designing and visualizing a **detailed network connection of our college** using **Cisco Packet Tracer**, along with problem analysis and solution implementation.

---

## 📑 Repository Contents

1. **Problem Statement**

   * Provided by Cisco Networking Academy (NetAcad) under the Cybersecurity and Networking domain.
   * I selected the **Cybersecurity** problem track.

2. **Proposed Solution**

   * Designed with the knowledge and skills gained during the Cisco internship.
   * Includes network architecture, security considerations, and system representation.

3. **Packet Tracer Files (.pkt)**

   * Complete visualization of the **entire college network** and its sub-networks.

4. **Documentation (PDFs)**

   * Problem statement explanation.
   * Step-by-step solution design with supporting visuals.

## 📝 How to Use

1. **Open Packet Tracer Files**

   * Install Cisco Packet Tracer.
   * Navigate to the `.pkt` files in this repository.
   * Double-click or open them within Packet Tracer to explore the network topology.

2. **Explore Network Components**

   * Click on devices to view configurations.
   * Check connections, IP addressing, VLANs, and security setups.

3. **Run Simulations**

   * Use the simulation mode in Packet Tracer to test data flow and network behavior.

4. **View Documentation**

   * Open the PDF files to read the problem statement explanation and detailed solution steps.
